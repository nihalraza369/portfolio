# Nehal Raza — Networking Portfolio

Next.js App Router + React, plain responsive CSS. No API keys or environment variables needed.

## Local setup
1. Install Node.js 20 or newer (Node 22 recommended).
2. Extract the ZIP and open a terminal in the folder containing package.json.
3. Run `npm install` then `npm run dev`.
4. Visit http://localhost:3000.

Production: `npm run build` then `npm start`.

Edit content and labs in app/page.js; styles in app/globals.css; metadata in app/layout.js. Replace public/NehalRaza_CV.pdf to update the downloadable resume. Contact uses mailto, not a backend. The topology illustration is conceptual; lab cards describe simulated practice from the CV, not production projects. No external fonts or image services required.
